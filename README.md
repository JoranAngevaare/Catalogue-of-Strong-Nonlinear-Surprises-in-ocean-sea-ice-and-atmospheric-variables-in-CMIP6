## Additional information in this folder
In addition to the publicly available data, we provide:
 1. A netcdf file with the cases (strong non-linear surprises, SNS).
 2. A script for handling the netcdf file.
 3. A script for creating figures for each SNS case in the netcdf file.
 4. The figures for each SNS case. Grouped by case number, category and model (see manuscript).
