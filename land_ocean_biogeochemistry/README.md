# land-obgc branch
This branch includes two newly added documents on the preliminary results from catalogues of strong non-linear surprises (SNSs) over i) land, which includes cases on vegetation components such as the Amazon and Congo basins and permafrost, and ii) obgc, which includes cases on the ocean-biogeochemistry components of the Earth system from CMIP6 model outputs.

# Ongoing, Preliminary Documents
This branch consists of two documents:
- Dramatic shifts over land: This contains the SNSs we found over land, which includes cases over the Amazon and the Congo basin, and land permafrost.
- Dramatic shifts over the ocean for the biogeochemistry components: This set of preliminary SNS cases consists of e.g., the collapse of the North Atlantic Bloom as a result of the subpolar gyre and/or AMOC collapse and strong decline of nutrients over the upwelling  regions on the west coast of South America.
